One line of at most 200 characters: the phone battery's final message to the charger it waited for all day. A judge model keeps the funnier of each pair, and the funniest lines split the pool. This deterministic Node program writes the line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
